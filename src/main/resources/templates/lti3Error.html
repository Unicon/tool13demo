The launch didn't complete

The tool stopped the launch for the reason below. Relaunching from the LMS usually helps; if it doesn't, the hint underneath says where to look.

What went wrong

Error

Likely cause

The tool has no registration that matches this LMS, developer key and deployment. Each install of the tool has its own deployment id, so a new course or account install needs its own record.

Add one with the values in the message (issuer, client id and deployment id) through /config/, or register the tool with Dynamic Registration. See "Registering a Platform Deployment" in the README.

The response didn't match a launch this tool started. This happens when a launch page is reloaded or reopened with the back button, when the launch took too long and the state expired, or when the browser blocked the storage the cookieless flow relies on.

Start again from the link in the LMS.

The ID token was issued for a different developer key or deployment than the one the launch started with. Check that the LMS install uses the client id and deployment id registered in the tool.
